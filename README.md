# Attila Menyhart

This is the repository for my personal website: [attila.menyh.art](https://attila.menyh.art), where I showcase projects that I have worked on.

## Usage

Feel free to use this repository as a template for your own personal website.

## Setup

To set up the project, follow these steps:

1. Clone the repository: `https://github.com/MAttila42/portfolio`
1. Install dependencies: `bun install`
1. Start the development server: `bun run dev`
1. Deploy the project to your preferred hosting service (e.g., Cloudflare)
